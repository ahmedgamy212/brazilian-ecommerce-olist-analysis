# Recruit Restaurant Visitor Forecasting

This directory contains a time-series forecasting project for the Recruit Restaurant Visitor Forecasting competition.

## Contents

- `Data/`: competition datasets in CSV and source ZIP formats
- `python/recruit-restaurant-visitor-forecasting.ipynb`: analysis and modeling notebook
- `python/*_profile.html`: generated dataset profiling reports
- `python/*_best_model.pkl`: trained CatBoost, LightGBM, and XGBoost model artifacts
- `python/model_comparison_summary.csv`: model comparison results

The large `Data/hpg_reserve*.csv` files are tracked with Git LFS. Install Git LFS before cloning or downloading these files.
