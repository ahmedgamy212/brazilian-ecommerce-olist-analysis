# Brazilian E-Commerce Olist Analysis

An end-to-end analysis of the Brazilian E-Commerce Public Dataset by Olist using Python, SQL, and Power BI.

## Contents

- `Python/`: exploratory analysis notebook and source CSV datasets
- `SQL/`: SQL queries used for analysis
- `Power BI/`: interactive Power BI report

## Tools

- Python and Jupyter Notebook
- SQL
- Microsoft Power BI

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available through Kaggle.

## Repository

This repository brings together data preparation, analysis queries, and dashboard reporting for the Olist e-commerce dataset.
